3 Heatmap Schedule Optimization
This fills in automatically from this month's data when the technician can be matched with confidence — otherwise, pull it from the Heatmap tool using the 10-week lookback. It's the technician's % booked for each day of the week, and the % booked for their service category at this location for the same days. Enter 0% for any day the technician is not scheduled — the tool treats 0% as not working that day. If the technician is working less-desirable days (Sunday–Tuesday for most categories; Monday–Tuesday for Body, since Sunday can be a desirable massage day) while category demand is high (70%+) on days they're not scheduled, the tool will suggest reviewing a schedule change to help them get busier — unless the technician is already booked 65%+ on that less-desirable day, in which case it's left alone. This section is always optional and never blocks Generate — but when productivity is below 80%, filling it in adds schedule-optimization coaching you'd otherwise miss.

4 Payroll & Compensation Optional
Reference the Compensation Dashboard for level lock status, qualification, and rate comparison before answering these questions.
A Minimum Wage Adjustment (MWA) means extra money is added to the technician's paycheck to bring their pay up to minimum wage, because their commission for the hours they worked came in below the minimum-wage equivalent. Frequent MWA is a signal worth discussing in the 1:1 — this question does not apply to California locations, which have different wage laws.
5 Title Promotion Data (last 3 months — used only for the Title Promotion Tracker) Optional
Enter the technician's total revenue, revenue per hour, and repeat rate for each of the last three months. Titles require each of the 3 months individually to meet the benchmark and repeat rate qualifier — averages are not used. This tracker checks the metric that matches the Employment Type selected in Step 1 (Total Revenue for Full Time, Revenue Per Hour for Part Time) applied consistently across all 3 months.

Note: DOMO determines Full Time vs. Part Time status separately for each month based on that month's actual scheduled hours (120+ hrs = Full Time, under 120 = Part Time) — so if this technician's hours varied month to month, DOMO may evaluate some months on Revenue and others on Revenue Per Hour. This tracker applies one employment type across all 3 months for simplicity, so treat it as an estimate and verify the official calculation in DOMO before promoting.
